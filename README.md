# context

A portable, user-owned context layer for the agent economy.

AI assistants relearn you from scratch every session, and your context is
trapped in silos that don't trust each other. **context** turns the richest
record of who you are — your own message history — into a portable profile
you review, edit, and hand to any assistant.

Local-first, non-negotiable: extraction and distillation both run on-device
(Gemma via Ollama). Raw messages never leave your Mac; the only artifact is
the profile you approve.

- `app/` — the macOS menu-bar app (Swift, SPM; builds with Command Line Tools only)
- `extract.py` — standalone Python extractor (prototype / scripting)

Download: https://context.nikliolios.com
