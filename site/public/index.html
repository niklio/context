context

Your AI assistants don't know you. Your messages do.

context reads your own iMessage history and distills it into a profile you review word-for-word, edit, and hand to Claude, ChatGPT, or Gemini — so every assistant starts from who you actually are.

Nothing leaves your Mac. Extraction and distillation both run on-device — the AI doing the reading is a local model (Gemma, via Ollama). The only artifact is the profile you approve.

Download for Mac
v0.1.0 · Apple Silicon · macOS 14+ · free · source

Install
  1. Unzip, drag Context Layer to Applications, then right-click → Open (unsigned beta).
  2. Install Ollama if you don't have it — the app handles the rest, including the one-time model download.
  3. Grant Full Disk Access when the app walks you through it (that's how it reads Messages; macOS doesn't allow a normal permission prompt).
  4. Click Build my profile, review, and inject.
